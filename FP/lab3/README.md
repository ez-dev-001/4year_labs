# Лабораторна робота №3 — варіант 4

У всіх питальних реченнях тексту підручника з програмування знайти й надрукувати
без повторень слова заданої довжини (Haskell).

## Типи

- `Symbol` — символ; `Word` — слово (список символів); `Punct` — розділовий знак та інші
  символи (дужки, оператори, лапки); `Token` — слово, знак, пробіл або межа абзацу;
  `Sentence` — речення; `Text` — текст.
- Клас `Render` з екземплярами для всіх типів збирає текст назад. Табуляції й послідовності
  пробілів при розборі згортаються в один пробіл.

## Правила розбору

- Речення закінчується на `.` `!` `?` `…` (а також `?!`, `...`, лапки чи дужки після знаку),
  якщо знак стоїть впритул до слова і далі йде пробіл або кінець тексту. Тому `3.14`,
  `System.out.println`, `main.c` і тернарний `a ? b : c` речення не рвуть.
- Порожній рядок — межа абзацу: заголовок без крапки не зливається з наступним реченням.
- Слово — літери, цифри, `_`, діакритика; апостроф і дефіс усередині слова (`м'який`,
  `будь-який`) його не рвуть. Довжина — кількість літер і цифр. Числа (`10`) словами не вважаються.
- «Без повторень» — без урахування регістру; «й», «ї» з окремою діакритикою збігаються зі звичайними.

## Збірка й запуск (Windows)

```
chcp 65001
ghc -O2 -outputdir build-main Main.hs -o lab3
lab3 textbook.txt 4
```

Файл має бути в UTF-8, не більше 16 МБ. Програма друкує питальні речення, їх кількість і
знайдені слова.

## Тести

```
ghc -O2 -outputdir build-test -main-is Test Test.hs -o test
test
```

`Test.hs` (51 перевірка, потребує зібраного `lab3` і `textbook.txt` поруч) перевіряє розбір на
типи, межі речень, питальні речення, довжину й відбір слів, безпечний вивід і програму цілком
(файл не в UTF-8, BOM, порожній файл, завеликий файл, некоректні аргументи).

Під час перевірки знайдено й виправлено: заголовки й рядки коду без крапки зливались із
питаннями; речення без слів («?!») рахувались питаннями; `;` у коді вважався знаком питання;
великий файл займав пам'ять у десятки разів більшу за свій розмір (тепер — один потоковий прохід
і обмеження розміру); керуючі символи з файлу доходили до терміналу (тепер показуються як `\x..`).
Додатково властивості перевірено на 20 000 випадкових текстів і 1000 файлів із довільних байтів.
