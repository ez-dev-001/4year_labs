Іванченко Владислав Віталійович, група ІПС-41.
Python 3.10+, PySide6 (Qt Widgets і Qt Multimedia з бекендом FFmpeg), pytest.
Повний звіт: `Звіт_ЛР2_РМС_Іванченко.pdf`.

## Запуск

```bash
pip install -r requirements.txt
python player.py                      # порожній плеєр
python player.py a.mp4 b.mp3          # відкрити файли або посилання одразу
python -m pytest -q                   # 66 тестів
python inject_faults.py               # перевірка тестів ін'єкцією помилок, близько 20 хв
```

## Що вміє

Вимоги варіанта: відкриття файлів і посилань (http, https, rtsp, rtmp, ftp), Play/Pause/Stop, перемотування на 5 с, смуга прогресу, поточний і загальний час, гучність. Перевірені формати: WAV, MP3, MP4, WebM, MKV.

Додатково:

- над смугою прогресу видно таймкод точки під курсором, клік переносить відтворення в цю точку;
- список відтворення: кілька файлів з діалогу або перетягуванням, попередній і наступний, автоперехід після кінця файлу;
- швидкість від 0.5× до 2×, повтор, повний екран, збереження поточного кадру в PNG;
- вимкнення звуку без втрати рівня гучності;
- зрозумілі повідомлення про помилки: файлу немає, це не медіафайл, посилання недоступне;
- порожній стан з підказкою, обкладинка з назвою для аудіо, назва файлу в заголовку вікна.

## Перевірка

66 тестів працюють зі справжніми медіафайлами і справжнім `QMediaPlayer`. Результати прогону на різних вхідних даних і тестування описано в розділах 7 і 8 звіту.

Розробка і тести йшли в Linux без звукової карти. Там Qt Multimedia сам зависає в кінці MP4 зі звуком AAC, тому тести автопереходу і повтору використовують WAV. На звичайному комп'ютері зі звуком цього обмеження бути не повинно.
